# 💙 Best Memories — Friendship Day Surprise Card

A beautiful, animated Friendship Day surprise card generator. Enter your name and your friend's name, and get a personalized card with a heartfelt message — ready to download, copy, or share.

## ✨ Features

- 🌌 Aurora + starry night animated background
- 📝 Personalized greeting based on sender & receiver names
- 🎁 Extra surprise reveal card
- 📥 Download card as an image (via `html2canvas`)
- 📋 Copy message to clipboard
- 📤 Share directly with friends
- 💻 Fully responsive, no backend required

## 🚀 Demo

Open `index.html` in your browser, or enable **GitHub Pages** on this repo to get a live link.

## 🛠️ Built With

- HTML5
- CSS3 (custom animations, gradients)
- JavaScript (vanilla)
- [html2canvas](https://html2canvas.hertzen.com/) — for card-to-image download
- Google Fonts — Poppins, Playfair Display, Great Vibes

## ▶️ How to Use

1. Clone the repo
   ```bash
   git clone https://github.com/wastavnagture97-pixel/Best-Memories.git
   ```
2. Open `index.html` in your browser.
3. Enter your name and your friend's name.
4. Click **✨ Generate Surprise**.
5. Download, copy, or share your card! 🎉
